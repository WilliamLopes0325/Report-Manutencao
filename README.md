# Report CFC

Página web para geração automática de relatórios de manutenção CFC.

## Funcionalidades

- Importação de Excel
- Filtro por turno
- Agrupamento por linha
- Geração de relatório para Outlook
- Copiar assunto
- Copiar report

## Turnos

- T3 → 00:00 até 06:29
- T1 → 06:30 até 14:59
- T2 → 15:00 até 23:59

## Tecnologias

- HTML
- CSS
- JavaScript
- SheetJS (XLSX)
